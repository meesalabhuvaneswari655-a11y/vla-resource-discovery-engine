## 3. End-to-End Implementation & Training Roadmap

### Step 1: Vision-Language Representation Initialization & Grounding
Initialize the multi-modal transformer backbone using pre-trained weights from Qwen2-VL (2B, 7B, 72B). Extract spatial patch tokens and project visual features into the language embedding space, ensuring high-resolution visual grounding for fine-grained object manipulation.

- **Key Components:** Qwen2-VL (2B, 7B, 72B), Hugging Face Transformers, PyTorch
- **Inputs:** High-resolution RGB camera streams + Natural language prompt embeddings
- **Outputs:** Pre-aligned visual-text token embeddings ready for action discretization or flow matching
- **Hardware Allocation:** 1x NVIDIA GPU with >= 24GB VRAM (e.g. RTX 4090 or A100)

### Step 2: Trajectory Ingestion & Policy Co-Fine-Tuning
Stream multi-embodiment demonstrations from Open X-Embodiment (OXE) Dataset using RLDS or Zarr data loaders. Fine-tune OpenVLA (7B) using LeRobot (Hugging Face). Employ Parameter-Efficient Fine-Tuning (PEFT / LoRA) or FSDP to adapt action tokens (Cartesian delta poses + gripper state) while preserving general knowledge.

- **Key Components:** LeRobot (Hugging Face), Open X-Embodiment (OXE) Dataset, OpenVLA (7B), PyTorch FSDP / PEFT
- **Inputs:** Multi-view robot trajectories (RGB + Proprioception) conditioned on instructions for 'object manipulation, instruction following'
- **Outputs:** Trained checkpoint weights with action chunking / auto-regressive action generation
- **Hardware Allocation:** 1x RTX 3080/4090 (ACT/Diffusion) or multi-GPU (VLAs)

### Step 3: Simulation Validation & Sim-to-Real Benchmark Rollout
Deploy policy checkpoints into ManiSkill 3 for zero-shot and domain-randomized policy rollout. Evaluate success rates across pick-and-place, articulated drawer opening, and unseen language instructions. Calculate Pearson correlation with physical benchmarks to prevent sim-to-real divergence.

- **Key Components:** ManiSkill 3, OpenVLA (7B), Vulkan / PhysX GPU Backend
- **Inputs:** Policy checkpoint weights + Standardized evaluation task environments
- **Outputs:** Task success rate metrics (SR%), trajectory completion time, and safety violation logs
- **Hardware Allocation:** NVIDIA GPU with Vulkan ray-tracing support (RTX 3070+ recommended)

### Step 4: Physical Hardware Deployment & Edge Inference
Export fine-tuned policy to ONNX or TensorRT-LLM for low-latency edge inference on the physical robot. Interface with robot controllers at 10Hz-50Hz using LeRobot (Hugging Face)'s hardware connectors. Deploy closed-loop safety filters with gripper force feedback and trajectory smoothing.

- **Key Components:** LeRobot (Hugging Face), ROS 2 / gRPC, TensorRT / bitsandbytes
- **Inputs:** Real-time camera feed (30 FPS) + Operator natural-language instructions
- **Outputs:** End-effector delta position commands (x, y, z, roll, pitch, yaw, gripper state)
- **Hardware Allocation:** 1x NVIDIA RTX 3090/4090 (with bfloat16/int4 quantization)
